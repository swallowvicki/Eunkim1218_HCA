(5) rejected_final — 거절, Resubmit ineligible (edit_allowed = false)29TFV Submission Content (new)목적
TFV Rejected 시 Sales/CS가 Twilio console 확인 없이 WA에서 벤더가 실제 제출한 문구를 확인하고 resubmit 안내.

데이터
· 벤더가 TFV 제출(최초/재제출)할 때마다 Twilio에 전송한 내용을 제출 건별 스냅샷으로 DB 저장
· 이유: Twilio는 Edit & resubmit 시 같은 verification 건을 수정 → 이전 제출 원문이 Twilio에 남지 않음
· EIN (Business registration type / number), Use case categories, Age gated content는 저장 불가 → 저장·표시 제외

진입
pending_review(제출) 행의 Description 열 View submission 링크 → 모달 (read-only, 최대 640px, 초과 시 본문 스크롤)

모달 구성
· 상단: 제출일 / Initial submission·Resubmission
· Review Result: 해당 제출 행의 Status (Pending + 날짜) / Error
· Toll-Free Number: Toll-free phone number
· Registration Information: Company / DBA / Business address / Business type / Business registration country / Business website / Privacy policy URL / Terms and conditions URL / Business contact name / Business email address / Business contact phone
· Use Case: Use case description / Estimated monthly SMS volume / Production message sample / Additional information
· Opt-in: Opt-in type / Opt-in proof / Opt-in keywords / Opt-in confirmation message / Help message sample
· Notification: Notification email
